# Retail Sales & Profitability Analysis

## Project Overview
An end-to-end data analytics project exploring retail sales, profitability, product performance, and regional trends.

## Business Objectives
- Analyze sales and profitability.
- Identify high- and low-performing product categories.
- Compare performance across regions.
- Investigate the relationship between discounts and profit.
- Develop evidence-based business recommendations.
